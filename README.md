# 하루 3끼 & 가계부 (v1.1)

오프라인 지원 모바일 PWA

## 기능
- **환경설정**: 하루 끼니 최대 **3끼** 제한
- **식사 옵션**: 밥+국, 찌개, 치킨, 파스타, 샐러드 등 + 영양정보
- **간식**: 과일 2~3개 권장 + 냉동블루베리, 컵라면, 베이글, 비타민주스 등
- **영양분석**: 칼로리/단백질/탄수화물/지방 합산 + 목표 대비 진행 바
- **찬장(보유재료)**: 별도 관리 — 추가/수정/삭제, 빠른 추가 재료
- **장바구니**: 추가/수정/삭제 + **「찬장으로」** 이동 가능
- **가계부**: 수입/지출 기록, 수정/삭제 가능
- **오프라인**: Service Worker + localStorage
- 홈 화면 설치 가능 (모바일 탭에서도 실행)

## 사용법
1. 로컬: `index.html` 열기 또는 `python -m http.server`
2. GitHub Pages 배포 후 접속
3. 브라우저에서 "홈 화면에 추가" → 앱처럼 사용
